# Neubrutalism Cartoon Portfolio - Abdullah Wijaya

Portfolio website dengan gaya desain **Neubrutalism** yang dikombinasikan dengan estetika kartun teknis. Dirancang khusus untuk mempresentasikan skill di bidang Networking (TKJ) dan Development.

## 🛠 Teknologi yang Digunakan
- **Frontend:** HTML5, Tailwind CSS (via CDN)
- **Fonts:** Space Grotesk, Bricolage Grotesque, JetBrains Mono
- **Icons:** Google Material Symbols
- **Animations:** CSS Keyframes & Intersection Observer API

## 📂 Struktur Folder
- `/assets`: Semua file media (images, icons).
- `/css`: Pemisahan styling berdasarkan fungsi (animasi, layout neubrutalism).
- `/js`: Logika interaksi dan konfigurasi tema.

## 🚀 Cara Menjalankan
1. Clone repository ini.
2. Buka `index.html` di browser favorit Anda.
3. Gunakan extension 'Live Server' di VS Code untuk pengalaman development terbaik.
